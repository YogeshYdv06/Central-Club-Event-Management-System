This is the exact pop-up the app shows after sign-in. It is the same markup, styles and validation used by student-profile.js on the Dashboard, Clubs and Events pages — running in demo mode so it works without a Firebase account. Nothing is written to Firestore here.

How it behaves in the real app

  • After Google sign-in the Dashboard stays on its loading state until the form is saved — the modal cannot be dismissed with Escape or by clicking outside.
  • Saving writes users/{uid} with studentProfileComplete: true, then the dashboard appears.
  • On every later visit the flag is read first, so the pop-up never appears again. The same check runs on Clubs and Events.
  • Admins are skipped, and a permitted read failure fails open so nobody gets locked out.
